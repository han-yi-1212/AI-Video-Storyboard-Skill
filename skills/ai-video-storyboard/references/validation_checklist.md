# 分镜校验清单（Storyboard Validation Checklist）

本文档供 Agent 在 STEP 5 自动校验时逐条核对使用，也可作为人工 QA 的验收标准。

---

## 🔴 P0 — 强制规则（Must Pass）

### P0-1 时长校验
- [ ] 逐个检查每个镜头的 `duration_seconds` 字段
- [ ] 所有镜头 `duration_seconds ≤ 3`
- [ ] 若总时长与目标片长偏差超过 ±10%，标注警告
- [ ] 拆分后的镜头之间无动作断裂

### P0-2 轴线校验
- [ ] 识别所有包含 2+ 角色的场景
- [ ] 每个多人场景有明确的轴线规划声明
- [ ] 相邻镜头间人物左右位置关系一致
- [ ] 人物视线方向符合空间关系
- [ ] 正反打镜头无跳轴
- [ ] 若存在越轴，有合理过渡镜头

### P0-3 情绪特写校验
- [ ] 标记所有 `emotion_intensity ≥ 7` 的情绪节点
- [ ] 每个高强度情绪节点至少对应一个 CU/ECU 镜头
- [ ] 优先使用正面面部特写
- [ ] 无无意义的重复情绪特写

---

## 🟡 P1 — 质量规则（Should Pass）

### P1-1 非机械旁白
- [ ] 统计 `source_type = "supplementary"` 的镜头数量
- [ ] 补充镜头占比 ≥ 20%（建议值）
- [ ] 补充镜头均服务于叙事/情绪/衔接
- [ ] 无旁白逐句对应画面的机械生成痕迹

### P1-2 连续性
- [ ] 人物服装/外貌在同一场景内一致
- [ ] 人物动作在相邻镜头间可衔接
- [ ] 物品位置/持有状态跨镜头一致
- [ ] 情绪变化曲线符合叙事逻辑
- [ ] 空间位置无不合理跳变

### P1-3 叙事服务
- [ ] 每个镜头可回答"这个镜头让观众看到/感受到什么"
- [ ] 无纯装饰性冗余镜头
- [ ] 镜头排列符合因果/时间逻辑

---

## 🟢 P2 — 功能优化（May Implement）

### P2-1 提示词质量
- [ ] 英文提示词无中文残留
- [ ] 包含角色锚点词（跨镜头一致性）
- [ ] 景别英文术语使用正确
- [ ] 运镜提示词包含速度描述
- [ ] MJ/Flux 提示词包含 `--ar 16:9` 等必要参数

### P2-2 声音设计
- [ ] 每个镜头均有 Ambience 层
- [ ] 关键动作有对应 Foley
- [ ] BGM 有动态变化标注（强弱、调性、乐器变化）
- [ ] 情绪高潮处声音设计与画面配合

### P2-3 修改支持
- [ ] 支持指定镜号修改
- [ ] 修改后重新执行完整校验
- [ ] 修改范围最小化，不影响已确认镜头

---

## 统计指标

| 指标 | 计算方式 | 建议值 |
|---|---|---|
| 平均镜头时长 | 总时长 / 镜头数 | 2.0–3.0s |
| 情绪特写占比 | CU/ECU 镜头数 / 总镜头数 | 30–60% |
| 补充镜头占比 | supplementary / 总镜头数 | ≥ 20% |
| 景别多样性 | 使用的不同景别类型数 | ≥ 4 种 |
| 运镜多样性 | 使用的不同运镜类型数 | ≥ 3 种 |
