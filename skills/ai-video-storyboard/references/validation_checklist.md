# 工业级 AI 视频分镜校验清单与验收标准手册
*(Storyboard Validation Checklist & Industrial Acceptance Criteria V1.1)*

本文档供 AI Agent 在 **STEP 5（自动规则校验）** 阶段执行程序化自检，同时作为影视导演、后期剪辑与 AI 视频工程师验收分镜方案的工业级质量手册。

---

## 一、最高指导准则

> [!IMPORTANT]
> **最高原则：不允许为了满足规则而牺牲影视叙事逻辑与视听张力！**  
> 所有校验项的核心目的在于规避 AI 工具的物理渲染缺陷与保证影视视听语法的空间严谨性，绝不得为了套用规则而强行破坏故事的人物动机、情感高潮或连贯节拍。

---

## 二、🔴 P0 级强制红线规则校验（Must Pass）

任何分镜方案必须 100% 通过以下所有 P0 项，若有任何不通过项，系统必须自动拦截、自修复并重构后方可交付。

### P0-1：单镜头时长硬性约束（≤ 3.0s）
- [ ] **数据源检查**：核查全部分镜的时间戳区间与 `duration_seconds` 数值。
- [ ] **3 秒截断**：没有任何单镜头的时长超过 3.0 秒（AI 视频模型防崩坏窗口）。
- [ ] **动作承接验证**：拆分的长情节镜头之间，必须具备微动态的逻辑递进，严禁同一个动作无变化机械切片。
- [ ] **节奏舒适度**：微短剧镜头切换节奏紧凑，平均单镜时长建议在 2.0s ~ 3.0s 之间。

### P0-2：180° 轴线与空间视线朝向守恒
- [ ] **双人/多角色场景轴线定义**：识别所有包含 2 人及以上交互的场景，必须有明确的轴线声明与安全半圆判定。
- [ ] **屏幕方向守恒（Screen Direction）**：
  - 人物 A 在画面左侧且面朝右侧，人物 B 在画面右侧且面朝左侧。
  - 正打（拍 A）与反打（拍 B）在全片中均严格维持该左右视线关系，严禁视线同向冲突。
- [ ] **过肩镜头（OTS）机位验证**：
  - 拍 A 时机位位于 B 的肩膀后方（A 在左看右）。
  - 拍 B 时机位位于 A 的肩膀后方（B 在右看左）。
- [ ] **越轴合规性验证**：全篇若出现越轴，必须且只能通过以下 3 种方式之一合规过渡：
  - 轨道移动镜头（Dolly/Tracking/Arc）越过轴线；
  - 插入位于轴线正上方的中性角度镜头（正对脸正面平视、俯拍或环境空镜头）；
  - 角色在画面中自然走位改变几何相对位置。
  - 严禁任何形式的生硬跳轴！

### P0-3：核心情绪节点特写外化表达
- [ ] **情绪高潮定位**：标记剧作解构卡中情绪张力达到 7 分以上的关键冲突或转折点。
- [ ] **特写覆盖率**：每个高潮点必须至少配置 1 个正面面部特写（CU/ECU）或手部/身体微动作特写。
- [ ] **面部特写优先**：优先采用能看清眼神、微表情、眼泪、咬牙等生理反应的正面/微侧面部特写，严禁仅用背影或大远景敷衍关键情绪。
- [ ] **特写克制性**：特写镜头必须落在刀刃上，严禁缺乏情绪动机的无意义泛滥特写。

## 三、🟡 P1 级质量与叙事流畅度校验（Should Pass）

### P1-1：非机械化旁白拆解与卡前自主视听设计
- [ ] **杜绝字画 1:1 映射**：严禁把旁白原句逐字机械匹配对应画面。
- [ ] **视听镜头丰富度**：
  - 包含建立环境与烘托时代氛围的建立镜头（Establishing Shot）；
  - 包含听者心理反应的无声反应镜头（Reaction Shot）；
  - 包含承载隐喻和细节线索的微距插入镜头（Inserts）。
- [ ] **有效镜头占比**：旁白补充镜头与反应镜头占总镜头比例必须 ≥ 25%。

### P1-2：跨镜头视觉与空间连续性（Continuity）
- [ ] **角色资产锁定**：同一角色的外貌锚点词（发型、脸型、肤色、年龄、体型）全片一致。
- [ ] **服装与道具守恒**：同一时间段内，服装款式、面料颜色及随身道具（手机、钥匙、武器等）持有状态前后镜头一致。
- [ ] **动作顺畅衔接（Match on Action）**：上一镜的切出动作与下一镜的切入动作必须在空间与时间上连贯。
- [ ] **光影色温统一**：同场景下主光源方向、色温（如 3200K 暖黄 / 6500K 冷蓝）与暗部反差比保持绝对统一。

### P1-3：防畸变单一微动态设计（Single Micro-action）
- [ ] **杜绝高危复合动作**：每个镜头仅设计一个单一、稳定的物理微动作（Single Micro-action）。
- [ ] **严禁复合串联**：严禁在单镜头中要求角色“站起、转身、跑向大门并开门”。必须严格按安全规则拆镜头。

### P1-4：画面叙事价值六连问审查
- [ ] 每一镜均能明确回答：当前戏剧任务是什么？观众看清了什么？人物情绪在何处？景别角度合理性？AI 生成稳定性？剪辑点连贯性？

## 四、🟢 P2 级工程与声音设计优化校验（May Implement）

### P2-1：双通道提示词工程规范
- [ ] **生图词（IMG）**：纯英文无残留中文；包含完整的角色/环境锚点；包含摄影构图与胶片质感词；携带 `--ar 16:9 --style raw` 等必要控制参数。
- [ ] **运镜词（MOT）**：严格拆解为 `Camera: [运镜, 速度]` 与 `Subject: [主体动作, 强度]` 规范结构；使用标准行业摄影术语（dolly, pan, tracking, tilt, static 等）。

### P2-2：全流程四轨声音工程规范
- [ ] **Ambience（环境声）**：每镜均标注真实的空间声底（如深夜雨声、办公室空调低频、都市车流）。
- [ ] **Foley（拟音）**：角色的微动作拟音（衣服布料摩擦、皮鞋敲击大理石、金属拔出音）。
- [ ] **SFX（特效声）**：配合转折与悬念的关键声效（雷声、心跳急促音、耳鸣声、断电声）。
- [ ] **BGM（配乐）**：标注旋律风格、主奏乐器、调性倾向以及动态强弱记号（pp, p, mp, mf, f, fff, sub-bass 等）。

## 五、13 项工业级验收标准清单（Acceptance Criteria）

在分镜正式交付或投入 AI 视频批量渲染流水线前，必须逐项比对并满足以下 13 项硬性条件：

| 验收编号 | 验收维度 | 核心检验逻辑 | 判定状态 |
|:---:|---|---|:---:|
| **AC-01** | **镜头时长硬约束** | 全片 100% 的分镜时长严格处于 1.0s ~ 3.0s 区间，无超长镜头。 | `[ ] PASS` |
| **AC-02** | **轴线空间合理性** | 双人及多人交互场景全流程无违规跳轴，视线对撞完全符合空间几何。 | `[ ] PASS` |
| **AC-03** | **越轴过渡合规性** | 若有艺术性越轴，必须有移动机位、中性正面镜头或角色走位作为合法过渡。 | `[ ] PASS` |
| **AC-04** | **核心情绪特写覆盖** | 核心冲突爆发点及心理转折处，至少配置 1 个以上的面部 CU/ECU 或手部特写。 | `[ ] PASS` |
| **AC-05** | **非机械化叙事设计** | 镜头设计脱离文字逐字翻译，建立镜头、倾听反应镜头及隐喻插入镜头充足。 | `[ ] PASS` |
| **AC-06** | **微动态物理可行性** | 每个分镜仅包含单一微动作，绝无复合运动，彻底消除 AI 视频畸变崩坏风险。 | `[ ] PASS` |
| **AC-07** | **角色外貌连续性** | 同一角色的英文外观描述（发型、脸型、肤色、体型）在所有生图 Prompt 中严格一致。 | `[ ] PASS` |
| **AC-08** | **服装与道具守恒性** | 同一场景序列内，角色衣服款式、材质、颜色及随身道具的持有状态完全守恒。 | `[ ] PASS` |
| **AC-09** | **光影氛围统一性** | 场景提示词中的主光源方向、色温、天气氛围与电影胶片调色词统一锁定。 | `[ ] PASS` |
| **AC-10** | **生图 Prompt 规范性** | IMG 提示词完全符合 Midjourney / Flux 语法，含景别词、画幅比例 `--ar 16:9` 与质量参数。 | `[ ] PASS` |
| **AC-11** | **运镜 Prompt 规范性** | MOT 提示词精准拆解为 `Camera:` 与 `Subject:` 双通道运动控制，术语标准化。 | `[ ] PASS` |
| **AC-12** | **四轨声音工程完备性** | 音频列必须完整包含 Ambience、Foley、SFX 及 BGM 的详细状态，指导后期混音。 | `[ ] PASS` |
| **AC-13** | **自检报告完整性** | 输出末尾必须附带七项自检与统计报告，且所有 P0 级强制项判定全部为 PASS。 | `[ ] PASS` |

## 六、分镜局部重构与迭代准则（Localized Iteration Protocol）

在人工审片或客户反馈后进行局部调整时，必须严格执行以下防护机制：

1. **局部锁定**：仅修改受变更影响的目标镜头（如“将镜 03 改为面部特写”），**严禁变动未涉及的其他镜头的提示词与参数**。
2. **前后剪辑点防护**：修改目标镜头时，自动复核与上一镜头（In-point）及下一镜头（Out-point）的机位角度、空间视线和动作承接状态。
3. **时码自动重算**：若在已有镜头中插入或删除镜头，自动重新排布镜号序号与时间戳。
4. **重新校验并输出 Diff**：局部修改完成后，重新跑通以上 13 项验收标准，并向用户交付明确的修改对比说明（Modified / Added / Deleted Shots）。
