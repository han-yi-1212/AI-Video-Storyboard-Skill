本文档为分镜编写中的镜头语言决策提供快速参考。

## 一、180° 轴线法则详解

### 基本原理

```
        轴线（Action Line）
  A ←————————————————→ B
        |
        |  ← 安全拍摄区域（同一侧）
        |
      摄影机只能在这一侧移动
```

当两个角色面对面时，他们之间形成一条假想的**轴线**（Action Line）。
摄影机必须始终保持在这条轴线的**同一侧**拍摄。

### 为什么不能越轴？

越轴会导致：
- 人物左右位置关系反转
- 人物视线方向错乱
- 观众空间感知混乱
- 剪辑后产生"跳跃感"

### 合理越轴的三种方法

1. **移动镜头越轴（Tracking/Dolly）**
   - 摄影机通过可见的运动从一侧平滑移动到另一侧
   - 观众跟随摄影机运动重新建立空间感

2. **中性角度过渡（Neutral Shot）**
   - 插入一个正面对称构图（正好在轴线上）
   - 之后可以从任意一侧继续拍摄

3. **角色移动重建（Character Movement）**
   - 角色在画面中移动位置
   - 自然地建立新的轴线关系

### 分镜中的标注方式

```
【轴线声明】
A（左）←→ B（右），摄影机在轴线下方（观众侧）

镜号 05：OTS-A（从 B 背后过肩拍 A） ← 轴线下方 ✅
镜号 06：OTS-B（从 A 背后过肩拍 B） ← 轴线下方 ✅
镜号 07：从轴线上方拍摄 ← ❌ 越轴！
```

## 二、景别选择决策树

```
这个镜头的目的是什么？
├── 建立环境/空间 → ELS 或 WS
├── 展示人物全身动作 → FS 或 MWS
├── 日常对话 → MS 或 MCU
├── 传达情绪 → CU 或 ECU
├── 展示关键细节/道具 → ECU (insert shot)
└── 揭示空间关系变化 → WS（重新建立镜头）
```

### 景别与情绪强度的关系

```
情绪强度:  低 ←————————————————————→ 高
景别:     ELS   WS   FS   MS   MCU   CU   ECU
          ↑                              ↑
        疏离/孤独                    亲密/压迫
```

### 景别切换规则

1. **避免相邻景别跳跃过大**（如 ELS 直接切 ECU）
   - 除非是故意的视觉冲击（match cut 或 jump cut）
2. **对话场景常用组合**：
   - 建立镜头（WS）→ 双人中景（MS）→ 正反打（MCU/CU）
3. **情绪递进常用组合**：
   - MS → MCU → CU → ECU（逐步推进）

## 三、运镜与情绪映射

### 推进（Dolly In / Push In）

- **效果**：增加压迫感、亲密感、聚焦感
- **速度含义**：
  - 极缓：悬疑揭示、深沉思考
  - 中速：注意力聚焦
  - 快速：惊吓、突发威胁

### 拉远（Dolly Out / Pull Out）

- **效果**：揭示环境、孤独感、释放感
- **速度含义**：
  - 极缓：孤独、渺小感渐显
  - 中速：场景揭示
  - 快速：震惊后的"抽离"

### 横移跟拍（Tracking）

- **效果**：跟随、陪伴、流动感
- **适用**：角色行走/奔跑、环境展示

### 手持晃动（Handheld）

- **效果**：不安、紧张、纪实感
- **强度**：
  - subtle shake：轻微焦虑
  - moderate shake：紧张追逐
  - heavy shake：混乱恐慌

### 固定镜头（Static / Locked-off）

- **效果**：凝视、庄重、让观众聚焦于画面内容
- **适用**：情绪特写、重要对白、仪式感场景

### 升降（Crane / Boom）

- **效果**：宏大、超越、视角转换
- **Crane Up**：从具体到宏观，释放感
- **Crane Down**：从宏观到具体，聚焦

### 环绕（Orbit / Arc）

- **效果**：仪式感、展示、时间凝固感
- **注意**：AI 生成工具对环绕的稳定性一般，建议控制在 90°以内

### 甩镜（Whip Pan）

- **效果**：突发、转折、时间跳跃
- **注意**：AI 生成时容易产生模糊，建议配合剪辑使用

## 四、剪辑衔接类型

| 衔接方式 | 英文 | 效果 | 适用场景 |
|---|---|---|---|
| 硬切 | Cut / Hard Cut | 干脆利落 | 对话、动作连续 |
| 叠化 | Dissolve / Cross Dissolve | 时间流逝、梦境 | 回忆、场景过渡 |
| 淡入 | Fade In | 开始、苏醒 | 影片开头 |
| 淡出 | Fade Out / Fade to Black | 结束、意识消失 | 影片结尾、场景结束 |
| 匹配剪辑 | Match Cut | 意象关联 | 隐喻、时空跳跃 |
| 跳切 | Jump Cut | 时间跳跃、焦虑 | 蒙太奇、内心混乱 |
| L 型剪辑 | L-Cut | 声音先于画面 | 对话场景 |
| J 型剪辑 | J-Cut | 画面先于声音 | 悬念、预期 |
| 白闪 | Flash / White Flash | 闪回、爆炸 | 记忆闪回 |

## 五、常见场景的标准镜头序列

### A. 双人对话场景

```
01. 建立镜头（WS）：双人全景，建立空间关系
02. 双人中景（MS）：开始对话
03. 正拍 A（MCU/CU）：A 说话
04. 反拍 B（MCU/CU）：B 回应
05. 反应镜头（CU）：A 听到后的表情反应
06. 情绪升级（ECU）：关键台词时的面部特写
07. 重新建立（MS/WS）：回到双人画面，确认空间关系
```

### B. 独处情绪场景

```
01. 环境建立（WS/ELS）：展示人物所在环境
02. 人物中景（MS/MCU）：展示人物状态
03. 细节/道具特写（ECU）：暗示情绪的物品
04. 面部特写（CU/ECU）：情绪表达
05. 手部/肢体特写（ECU）：情绪外化动作
06. 环境回拉（MS→WS）：情绪释放，回归环境
```

### C. 追逐/紧张场景

```
01. 全景建立（WS）：展示追逐空间
02. 跟拍（Tracking MS）：跟随奔跑
03. 回头表情（CU, handheld）：紧张/恐惧
04. 脚步特写（ECU）：加速感
05. POV 镜头：第一人称视角
06. 障碍/转角（MS）：空间变化
07. 喘息特写（ECU）：疲惫/崩溃
```

## 六、AI 视频生成安全动作清单

### ✅ 安全动作（AI 可稳定生成）

- 静坐、站立、缓慢行走
- 头部缓慢转动
- 面部微表情变化
- 眨眼、嘴唇微动
- 头发随风飘动
- 手指轻微动作
- 缓慢拿起/放下小物品
- 低头/抬头
- 泪水滑落
- 呼吸起伏

### ⚠️ 中等风险动作（需谨慎使用）

- 站起/坐下
- 快走/慢跑
- 转身
- 伸手/指向
- 拥抱（静态姿势更安全）
- 敲门/按按钮

### ❌ 高风险动作（建议拆分或规避）

- 快速奔跑
- 跳跃/翻滚
- 打斗/搏击
- 多人复杂互动
- 换装/穿脱衣物
- 驾驶车辆
- 物品投掷/接住
- 全身舞蹈动作
