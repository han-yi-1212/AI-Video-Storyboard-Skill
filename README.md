# 🎬 AI 视频微短剧分镜编剧 Skill

> 将故事创意转化为符合影视镜头语言的标准化工业分镜表，输出兼容 Midjourney / Flux / Runway / Kling / MiniMax 等主流 AI 视频生成工具链的英文提示词与运镜控制参数。

## 📌 定位

专注服务于 **1~3 分钟** 的微短剧、叙事短片创作，注重多幕结构、戏剧冲突与人物情绪起伏。

**核心价值**：解决传统剧本无法直接用于 AI 视频生成的痛点，确保输出内容兼具「影视文学叙事」与「高可行性的 AI 视频工业控制参数」。

## 📂 文件结构

```
skills/ai-video-storyboard/
├── SKILL.md                        # 核心 Skill 定义（System Prompt）
└── references/
    ├── validation_checklist.md      # P0/P1/P2 分镜校验清单
    ├── prompt_engineering_guide.md  # AI 工具提示词工程手册
    └── cinematic_language_guide.md  # 影视镜头语言速查
```

## 🚀 核心功能

| 功能 | 说明 |
|---|---|
| **剧作架构拆解** | 三幕式结构梳理（Hook → 冲突递进 → 高潮反转 → 结局余味） |
| **视觉锚点锁定** | 角色外貌/服装英文锚点词 + 场景影调基调，确保跨镜头一致性 |
| **工业分镜表生成** | 6 列标准 Markdown 表格，含双轨英文提示词（图像 + 运动控制） |
| **自动规则校验** | P0 强制规则自动检查与修正（时长 ≤3s / 180° 轴线 / 情绪特写） |
| **反馈迭代** | 支持逐镜修改，保留已确认镜头 |

## 📏 核心规则

| 优先级 | 规则 | 说明 |
|---|---|---|
| 🔴 P0 | 单镜头 ≤ 3 秒 | AI 生成工具在 3s 内一致性最佳 |
| 🔴 P0 | 180° 轴线法则 | 双人对话禁止无过渡越轴 |
| 🔴 P0 | 情绪视觉特写 | 关键情绪必须有面部/手部特写 |
| 🟡 P1 | 非机械旁白 | 不逐句匹配旁白，需补充叙事镜头 |
| 🟡 P1 | 镜头连续性 | 动作、位置、物品状态跨镜头一致 |

## 🛠️ 兼容工具

- **图像生成**：Midjourney v6/v7、Flux
- **视频生成**：Runway Gen-3/4 Alpha、Kling 1.6+、MiniMax Hailuo

## 📖 使用方法

将 `SKILL.md` 作为 System Prompt 加载到你的 AI Agent / ChatGPT / Claude 中，然后提供你的故事创意即可。

Skill 会自动执行 6 步工作流：
1. 剧作架构拆解
2. 视觉资产锚点锁定
3. 场景轴线规划
4. 标准化分镜表生成
5. 自动规则校验
6. 输出 & 反馈迭代
