## 📌 核心定位与设计哲学

专为 **1~3 分钟** 微短剧、电影级叙事短片及 AI 视频前期卡前设计（Pre-visualization）打造。

> [!IMPORTANT]
> **最高原则：绝不允许为了死板满足规则而牺牲影视叙事逻辑与视听张力！**  
> 规则是保障 AI 视频生成可行性与空间几何严谨性的工业底线，而镜头的灵魂在于叙事推进、人物情绪起伏与观众心理节奏。

传统剧本或旁白无法直接用于 AI 视频生成的痛点：
1. **时长失控**：单镜头过长导致 AI 生成时人物面部漂移、肢体穿模崩坏。
2. **空间错乱**：缺乏 180° 轴线概念，正反打镜头视线同向，让观众空间认知崩塌。
3. **字画机械对应**：只是把旁白干瘪地画成画面，缺乏影视视听语言（无环境建立、无心理反应、无情绪特写）。
4. **复合动作崩坏**：让 AI 在单镜头内完成“站起+转身+跑步+开门”，物理引擎必然崩溃。

本 Skill 彻底解决上述痛点，提供工业生产级的全流程解决方案。

## 🚀 六步工业级工作流

```
用户输入（故事/剧本/旁白/创意）
        │
        ▼
[STEP 1] 剧本深度理解与七维架构剖析 ── 分析事件、动机、人物关系、攻防态势、空间与张力曲线
        │
        ▼
[STEP 2] 视觉资产与一致性锚点锁定   ── 角色英文外貌/服装锚点词 (Anchor Tokens) + 场景影调
        │
        ▼
[STEP 3] 空间几何建模与 180° 轴线规划 ── 建立人物三维相对坐标、视线朝向与安全摄影半圆
        │
        ▼
[STEP 4] 工业级 17 字段分镜方案生成  ── 标准 6 列表格 + 双通道提示词 + 四轨声音工程
        │
        ▼
[STEP 5] 自动化七项深度规则自检     ── 运行时严密拦截时长、越轴、特写缺失与复合动作
        │
        ▼
[STEP 6] 交付呈现与局部重构反馈机制  ── 锁死未修改镜头，保护剪辑点与时码自动重排
```

## 📏 核心规则与工业约束

### 🔴 P0 级强制红线（Must Pass，违规自动重构）
1. **单镜头时长严格 ≤ 3.0s**：顺应扩散模型物理窗口，超过时长必须进行有逻辑递进的视听拆分。
2. **180° 轴线法则与视线守恒**：严格建立对话轴线，双人正反打屏幕方向与过肩机位绝对守恒，越轴必须有合规过渡（移动机位/中性镜头/走位）。
3. **情绪特写外化表达**：张力 ≥ 7 的关键节点必须配置正面面部特写（CU/ECU）或手部微动作特写，拒绝远景带过。

### 🟡 P1 级质量标准（Should Pass）
1. **拒绝机械匹配旁白**：在卡前阶段主动设计建立镜头（WS）、倾听反应镜头（Reaction）及隐喻插入镜头（Inserts）。
2. **严格视觉连续性**：角色外貌、服装面料、随身道具持有状态及环境色温在跨镜头间绝对守恒。
3. **单一微动态（Single Micro-action）**：一个镜头只做一个单一微动作，根除复合动作畸变隐患。

## 📋 13 项工业级验收标准（Acceptance Criteria）

| 编号 | 验收维度 | 验收标准说明 |
|:---:|---|---|
| **AC-01** | **镜头时长硬约束** | 100% 镜头时长处于 1.0s~3.0s 区间，无超长镜头。 |
| **AC-02** | **轴线空间合理性** | 双人及多人交互全流程无违规跳轴，视线对撞吻合空间几何。 |
| **AC-03** | **越轴过渡规范性** | 艺术越轴必须具备轨道移动镜头、中性正面镜头或走位过渡。 |
| **AC-04** | **核心情绪特写覆盖** | 冲突爆发点与心理转折点均配置 CU/ECU 或手部特写。 |
| **AC-05** | **非机械化叙事设计** | 脱离逐字直译，建立镜头、反应镜头与插入镜头占比 ≥ 25%。 |
| **AC-06** | **微动态物理可行性** | 每个分镜仅含单一微动作，杜绝多动复合，消除 AI 畸变。 |
| **AC-07** | **角色外貌连续性** | 角色英文外貌描述（发型/脸型/肤色/体型）在所有提示词中一致。 |
| **AC-08** | **服装与道具守恒性** | 同序列内服装款式、面料颜色及道具持有状态严格闭环。 |
| **AC-09** | **光影氛围统一性** | 场景主光源方向、色温与胶片调色词统一锁定。 |
| **AC-10** | **生图 Prompt 规范** | IMG 提示词符合 Midjourney/Flux 语法并带 `--ar 16:9`。 |
| **AC-11** | **运镜 Prompt 规范** | MOT 提示词采用 `Camera:` 与 `Subject:` 双通道标准化控制。 |
| **AC-12** | **四轨声音工程完备** | 完整包含 Ambience、Foley、SFX 及 BGM 四层混音指引。 |
| **AC-13** | **自检报告完整性** | 输出末尾附带七项自检与统计报告，P0 项判定全部为 PASS。 |

## 🛠️ 兼容 AI 工具链

| 环节 | 主流支持工具 | 提示词输出标准 |
|---|---|---|
| **起始帧图像生成** | Midjourney v6/v7, Flux 1.0, Stable Diffusion 3 | 含角色/环境锚点、景别、胶片质感，带 `--ar 16:9 --style raw` |
| **视频运镜与动力学** | Runway Gen-3/4 Alpha, Kling 1.6+, MiniMax Hailuo | 拆解为 `Camera: [运镜, 速度]` 与 `Subject: [微动态, 强度]` |
| **音频与音效制作** | Suno, Udio, ElevenLabs, Epidemic Sound | 详尽标注环境底噪、拟音动作、情节声效与乐器调性强弱 |

## 📖 使用方法

1. 将 [SKILL.md](skills/ai-video-storyboard/SKILL.md) 作为 System Prompt 加载到你的 AI 平台（如 Antigravity IDE、ChatGPT、Claude、Cursor、Dify 等）。
2. 输入你的故事创意、短片大纲或旁白文案（例如：“深秋雨夜，女调查员在空旷办公室偷偷拷取机密，突然门外传来脚步声...”）。
3. Skill 将全自动完成七维解构、视觉锚点锁定、轴线推演、分镜生成与自检报告交付！
