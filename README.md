## 🔥 v5.0 商业级核心进化

### 1. 黄金 3 秒视觉钩子优先（Visual Hook First）
- **破除小说流水账慢热**：海外短剧前 3 秒划走率高达 70%，杜绝平铺直叙的回忆、端坐喝茶或长篇内心独白。
- **开局即高能**：第 1 镜头直接抛出强冲突、视觉奇观或悬念误导，瞬间拉满观众留存率。

### 2. 极致人设反差萌（Extreme Character Contrast）
- 将角色的多重身份对撞视觉化（如：冷艳硬核的战术女特工保镖 vs 萌乱拆家的萌宝大作战）。
- 创造天然的病毒式话题度与情感共鸣。

### 3. 高热度荷尔蒙张力与 Open 尺度（High Heat & Alpha Magnetism）
- 聚焦欧美付费短剧的核心爽点：**极致体型差、强硬肉体触碰（大掌掐腰、近距贴颈、气息交缠、指压深痕）、野性支配欲与兽性觉醒**。
- 每一个肢体接触都充满拉扯感与性张力（Tension & Heat）。

### 4. 严苛的好莱坞工业视听规范（保留 v4.0 全部技术资产）
- **置顶《全片统一视觉规范》**：角色统一、摄影风格、光影逻辑（冷暖色温分割）、表演规范（红线禁令）。
- **九维标准化分镜**：包含独立的 **【光线氛围】** 与 **【转场衔接】** 字段，重要高潮戏采用 **0.X 秒分秒级物理切分**。
- **置尾质检闭环**：《全片最终执行要求》与《最终画面情感》。
- **双语战略**：纯英文对白/画外音（每秒 ≤ 3.5 词精确口型契合） + 专业中文导演视听提示词。
