# 🎬 AI 电影级短剧分镜导演系统 v4.0

> **面向海外短剧市场的电影级分镜生成系统**：以好莱坞工业剧情片质感为标杆，输出包含《全片统一视觉规范》、九维标准化分镜（涵盖独立的【光线氛围】与【转场衔接】、高潮戏 0.X 秒物理动作切分）、以及《全片最终执行要求》与《最终画面情感》。**对白与画外音采用地道纯英文（English Dialogue/Voiceover），视听提示词全部采用中文，单集总时长严格控制在 1:30 左右（90秒）。**

## 🚀 v4.0 核心工业级升级

### 1. 独立标准化字段：【光线氛围】与【转场衔接】
- **【光线氛围】**：独立控制主光、辅光、轮廓光、色温（如 3200K 暖黄灯光与 6500K 冷蓝月光分割）、光比反差、阴影深浅以及瞳孔微光/水光，为 Sora、Runway Gen-3、可灵 AI 提供最高确定性的光影渲染参数。
- **【转场衔接】**：明确动作匹配剪辑（Match Cut）、同构图跳切（Jump Cut）、声画错位引出（J-Cut/L-Cut）等影视剪辑指令，杜绝镜头间割裂。

### 2. 置顶《全片统一视觉规范》（四位一体锁定）
每个分镜文档前置强制设定：
- **角色统一**：锁定人物五官微特征、发型、标志性服饰道具与物理一致性。
- **摄影风格**：电影级画质、真实皮肤纹理、浅景深高宽容度、机械运动惯性。
- **光影逻辑**：严密的场景冷暖色温分割体系（如日戏高对比冷白光；深夜室内外冷暖对冲）。
- **表演规范（红线禁令）**：禁止面瘫木讷、禁止突兀嚎啕大哭或浮夸咆哮，动作触发微表情。

### 3. 高潮戏分秒级物理切分（0.X 秒动作链）
重要情感爆发与剧情转折镜头，采用次级时间切分（如 `00:00.0-00:00.8`、`00:00.8-00:01.7`），把微表情细化为肌肉收缩、指节泛白、喉结滚动、咬牙呼吸等连续的生理物理链。

### 4. 置尾闭环质检：《全片最终执行要求》与《最终画面情感》
- **执行要求**：8~10 条严格的导演执行红线（时间轴闭合、180度轴线规则、英文语速匹配、光源方位守恒等）。
- **最终画面情感**：提炼全片深层情感落点，赋予作品深刻的电影文学余韵。

### 5. 海外短剧双语战略架构
- **对白与画外音（Dialogue & Voiceover）**：地道纯英文，精确匹配口型与真实说话语速（每秒 ≤ 3.5 单词）。
- **视听提示词（Visual Prompts）**：全中文标准专业术语，方便创作者和导演团队直观阅读、调整与直接复制投喂给大模型。

## 🌟 实战示范：《逆光审判 / The Broken Covenant》

从一段浓烈的高潮剧本：

> Vivian slammed the waterlogged manuscript onto the mahogany desk. "Did you really believe I sold your father's legacy for five million dollars? Look at the signature, Damian! Look at the date!"

转化为好莱坞级九维分镜，精准包含：
- 💡 **冷暖光影工程**（窗外 6500K 暴雨闪电 vs 室内 3000K 暖黄孤灯）
- ⏱️ **0.X 秒物理拆解**（手套揉皱信纸、按桌指骨发白惨白、瞳孔剧震）
- 🎬 **电影剪辑衔接**（受力下压动作匹配、雷光闪烁切出）
- 🗣️ **纯英文同期对白**（严格口型同步与破音气声）

👉 查看完整商业级示范文档：[examples/ai_call_showcase.md](examples/ai_call_showcase.md)

## 📋 标准分镜格式规范

```
[开始时间-结束时间] 镜头N：[场景/核心动作小标题]

**场景：**
[时间属性，具体地点环境，空间结构与陈设]

**景别：**
[主体 + 景别演进，如：大全景 → 中远景 → 正面半身近景]

**机位：**
[摄影机初始物理位置、相对角色的几何关系与终点]

**拍摄角度：**
[明确几何度数，如：高位俯拍30° → 逐渐下降 → 正面微俯拍8°]

**运镜：**
[具有真实机械惯性的工业级运镜描述，如：吊臂下降结合导轨推进]

**光线氛围：**
[主光/辅光/轮廓光、冷暖色温对比、明暗交界线、瞳孔反光与眼底水光]

**画面动作表演：**
[普通镜头连贯描写 / 高潮戏分秒级 0.X 秒次级物理动作链切分]

**【对白/口型】**
[英文台词/画外音，标注口型同步状态，严格契合镜头时长]

**【音效同步】**
[人声前景 + 动作拟音细节 + 环境空间底噪 + 心理低频音效]

**【转场衔接】**
[匹配剪辑 / 同构图跳切 / 硬切 / 声画错位引出等剪辑指示]
```

## 📖 使用方法

1. **导入 Prompt**：将 [SKILL.md](skills/ai-video-storyboard/SKILL.md) 载入到支持的 AI 平台（Claude、ChatGPT、Dify、Coze、Antigravity IDE 等）；
2. **输入剧本**：将任意海外短剧剧本或剧情大纲发送给 AI；
3. **获取成品**：AI 将输出包含前置视觉规范、九维分镜本体、以及尾部执行要求与画面情感的完整标准脚本，可直接一键全选复制。
