# 🎬 AI 短剧分镜师 Skill v3.0

> **纯中文 AI 短剧分镜创作系统**：根据剧本内容自动拆解为标准化视频分镜镜头，每个分镜包含时间轴、景别、机位、拍摄角度、运镜方式、画面动作表演（含微表情与情绪状态）、对白/口型和音效同步。**情绪表达优先，输出可直接复制使用。**

## 🚀 v3.0 核心特性

### 纯中文分镜输出
所有提示词、描述、对白全部使用中文，不包含任何英文 AI 工具参数（如 `--cref`、`--sref`、`--ar` 等），输出结果可直接复制使用。

### 情绪优先
分镜创作的第一原则是**情绪表达**。每个镜头的景别、角度、运镜都服务于角色当下的情绪状态。要求：
- 情绪外化为具体的身体语言（微表情、手部动作、呼吸变化）
- 捕捉复合情绪（愤怒中夹杂心疼、冷漠下掩盖悲伤）
- 情绪爆发点必须给特写或超特写
- 沉默与留白同样是重要的情绪表达

### 单集时长严格控制在 1:30 左右（90秒）
- **单集基准时长**：每集分镜总时长严格控制在 **01:30 左右（85s ~ 95s，基准 90 秒）**。
- **镜头量与节奏**：单集通常包含 **24 ~ 30 个镜头**，通过快慢节奏交替、丰富的特写与倾听反应镜头充实 90 秒叙事空间，避免情节压缩或匆促断层。

### 标准化分镜格式
每个分镜严格按照以下格式输出：

```
[开始时间-结束时间] 镜头N：
景别：[人物/主体] + [特写/近景/中景/全景]
机位：[摄影机所在位置/相对角色的位置]
拍摄角度：[正面/侧面/前侧45度/俯拍/仰拍/平视]
运镜：[固定镜头/推近/拉远/横移/跟随/轻微推近等]
画面动作表演：[角色在镜头里的动作过程 + 微表情 + 情绪状态 + 是否在此时说话/何时说话]
【对白/口型】：[无 / 角色名："台词" / 画外音 / 内心独白]
【音效同步】：[人物声音]，[动作音效]，[环境音]
```

### 📺 示范案例：《黑狼族总统的秘密》E02 重逢

从一段剧本文字：

> "总统大人！"后面的助理紧张地呼喊。我的血液瞬间凝固了。我抬起头，对上了一双金色的眼睛……

- 🎵 **精准的音效设计**（心跳声渐强、脚步的节奏断裂、远去的回响）
- ⏱️ **有呼吸感的节奏编排**（对视的慢镜 vs 错身的快切）

## 📋 核心创作规则速览

| 规则 | 说明 |
|---|---|
| **情绪外化** | 不写"角色很伤心"，要写出伤心的具体身体表现 |
| **一镜一动** | 一个镜头只做一件事，严禁复合动作 |
| **台词限制** | 单镜头台词字数 ≤ 时长(秒) × 4.5 字 |
| **节奏呼吸** | 快切（1.0s~1.5s）与慢镜（2.5s~3.0s）交替 |
| **视线一致** | 对话双方的画面位置和视线方向全程保持一致 |
| **特写时机** | 情绪爆发点、真相揭示、内心转折必须给特写 |
| **沉默留白** | 无台词的反应镜头同样重要，捕捉身体语言 |

## 📖 使用方法

1. **复制 System Prompt**：将 [SKILL.md](skills/ai-video-storyboard/SKILL.md) 的内容复制到你的 AI 平台（Claude、ChatGPT、Dify、Coze、Antigravity IDE 等）
2. **发送剧本**：把你要拆解的剧本内容发给 AI
3. **获取分镜**：AI 会输出一整段可直接复制使用的标准化分镜提示词

### 可选参数

你可以在发送剧本时额外说明：
- 预期片长（每集约60秒、90秒、2分钟等）
- 风格基调（冷峻悬疑、暗黑虐恋、温暖治愈、爽剧节奏等）
- 重点情绪（如"这场戏核心是隐忍的心疼"）
- 特殊要求（需要更多快切、某角色需要更多特写等）
